# aitrongcay — prototype website polished

Prototype static cho dự án **"vườn thuê số hóa"**, bám Mẫu 1 **"Vườn Riêng Trong Tầm Tay"**.

## Mở nhanh

Entrypoint chính:

- `index.html`

Chỉ cần mở file này bằng trình duyệt là có thể duyệt toàn bộ website như một khách hàng thật.

## Những gì đã được polish thêm

- Visual system đồng bộ hơn: typography, spacing, card depth, gradients, hover, badges.
- Homepage dày hơn với storytelling, device mockup, value strips, tab/accordion và CTA rõ hơn.
- FAQ chuyển sang interaction accordion.
- Portal pages được làm “giống sản phẩm thật” hơn với hero KPI, fake charts, progress bars, widgets và timeline phong phú hơn.
- JS tĩnh có thêm interaction cho:
  - mobile menu
  - fake submit notice
  - accordions
  - tabs
  - progress animation
  - rotating text

## Ghi chú

- Đây vẫn là prototype **HTML/CSS/JS tĩnh**, chưa nối backend thật.
- Các form đều là luồng demo, đủ để owner duyệt UX/UI và cấu trúc trang.
- Không có DB/schema trong repo này.
