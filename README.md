# Ai trồng cây

Website cho dự án **Ai trồng cây**.

## Cách mở website trên máy local

### Cách 1: chạy local server

```bash
npm start
```

Sau đó mở:

- `http://127.0.0.1:4173/`

Hoặc:

- `http://127.0.0.1:4173/index.html`

### Cách 2: mở trực tiếp file HTML

- `index.html`
